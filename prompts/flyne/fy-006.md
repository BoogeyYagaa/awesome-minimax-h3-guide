**Reference map:** Image 1 = consenting adult presenter; Image 2 = approved reception background.

**Use conditions / 使用条件:** Confirm a compatible route / 需先确认平台支持。Prepare the listed references and verify duration and input roles; do not treat multiple references as a first/last-frame pair. This is not ready to paste unchanged into the free tool. [Guide / 说明](../../docs/recipe-usage.md).

## Copy-ready prompt

```text
Create one welcoming receptionist shot using the adult in Image 1 and the room in Image 2. One second of quiet eye contact, then the presenter says exactly: “Welcome. I can help you find your room.” Finish with a relaxed closed-mouth smile and a small gesture toward the desk. Fixed eye-level camera, restrained expression, soft room tone, no music or generated subtitles. Preserve face, clothing and furniture. Produce the Chinese-language version in a separate run using only: “欢迎，我可以帮您找到房间。” Keep every visual instruction unchanged.
```

**Acceptance:** A fluent reviewer checks wording, tone, lip alignment and identity in both outputs.

**Recovery:** Shorten the sentence or use approved voiceover and a non-speaking shot.

**Production value:** Separates language variation from visual variation for easier localization review.

The duration is a creative target, not an API parameter guarantee. Select a compatible route in the [workflow guide](../../docs/workflows.md), record results with the [run template](../../templates/run-record.json), and verify input rights before use.
